This host runs a boidscan node

boidscan is a free and open source index of publicly reachable services. Nodes connect to public IPv4 addresses, record what services announce during a normal handshake (banners, HTTP responses, TLS certificates), and publish the results openly. No credentials are tried and no vulnerabilities are exploited.

Do not want to be scanned?

Run curl -X POST http://<any boid>/api/v1/optout on the host you want left alone. The opt-out covers exactly the IPv4 address the request comes from, reaches every boid in the flock, and deletes the results stored for that address. It lasts a year; run the command again to renew it. curl http://<any boid>/api/v1/optout shows its state and curl -X DELETE http://<any boid>/api/v1/optout withdraws it. Opt-outs in force are listed at /fed/v1/optouts.

For a whole network, block the scanning addresses in your firewall. This node scans from the address this page is served on.{{if .Flock}} The addresses of every boid this node knows are at /fed/v1/scanners, one per line. Boids join and leave, so fetch the list regularly.{{end}} A firewall does not delete results that were already collected. Questions go to {{.AbuseContact}}.
